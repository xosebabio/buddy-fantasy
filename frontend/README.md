# buddy-fantasy · frontend

Web Angular mobile first del fantasy. Reglas en `docs/requirements.md` (FE-01 a FE-35), resumidas en `docs/agents/frontend.md`; comandos en `docs/agents/commands.md`.

```bash
npm ci
npm start              # http://localhost:4200, con proxy al backend de localhost:8080
npm run lint           # ESLint y Stylelint, sin avisos
npm test               # Vitest
npm run build          # build de producción en dist/
```
